# Data Protection Impact Assessment (DPIA)

Only a Significant Data Fiduciary has to carry out a DPIA every year (Act s.10(2)(c), Rules r.13). Any business can still use one before it starts a new use of personal data, for example:

- a new module;
- a new processor;
- biometric attendance;
- CCTV;
- sharing data with a new partner;
- importing a large list of people.

It takes an hour, and it is the record that shows the decision was thought through.
